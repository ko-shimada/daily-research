Cloud SDK

GA / Deprecation最終: 7/21公式ソース

gcloud 577.0.0が公開されました。gcloud agent-identity auth-providersとgcloud agent-identity access-summariesが正式GAになった一方、gcloud computeのCSEK(顧客管理暗号鍵)関連フラグは非推奨になりました。セキュリティ修正の記載はありません。

Genesys Cloud

Voice / Copilot最終: 7/20公式ソース

設定可能な留守番電話検知(AMD)とサイレントコールタイムアウト、カンファレンスコールの秘匿保留、トランスクリプトセグメンテーション、Journey Managementの外部イベント管理が追加されました。Agent Copilotのインテントヘルスインサイトと利用状況ダッシュボード、ServiceNow ITSM連携、EU Sovereignリージョン展開、ArchitectのPolish語対応も掲載されていますが、いずれも対象外機能です。TTS Connector(BYOT)の記載もありますが7/13記載のGAと同一機能の再掲とみられます。Dialogflow CX連携や日本語音声処理への直接影響は確認していません。

BigQuery

GA / Preview最終: 7/20公式ソース

7/17付でKnowledge Catalogのデータリネージ制御がGAになりました。組織/フォルダ/プロジェクト単位でリネージ取り込みを制御でき、対象はBigQuery、Managed Service for Apache Spark、Managed Service for Apache Airflowです。7/20付ではLakehouse for Apache IcebergがSAP Business Data Cloud(BDC)と統合されました(Preview)。Delta Sharingカタログの自動同期、SAPデータの直接クエリ、Iceberg REST CatalogテーブルやKnowledge CatalogデータプロダクトのSAP BDCへの公開が可能です。現行の会話ログ分析基盤への直接影響は確認していません。

Cloud Storage

Feature最終: 7/20公式ソース

Object Lifecycle Managementの条件にサイズしきい値(sizeAboveBytes/sizeBelowBytes)が追加されました。最小/最大サイズを指定してライフサイクルアクションを発動できるため、音声ログや学習データバケットの容量ベース自動移行・削除ルール設計に使えます。
