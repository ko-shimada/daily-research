詳細

Genesys Cloud

Feature / Virtual Agent最終: 8/10公式ソース

8月10日リリースで、Agentic Virtual Agentsのツール出力値に対してプログラム的な事後条件を定義できるようになりました。特定のツール結果を自然言語指示へマッピングし、複雑な業務プロセスの応答をプロンプトだけに依存せず安定させる機能です。StatusではAsia Pacific (Tokyo / Osaka) はOperational、EMEA (UAE) PlatformはMajor Outage継続です。

BigQuery

Deprecated / GenAI最終: 8/12公式ソース

8月12日付でTable Explorerの動作がReferenceパネルへ移行し、Table Explorerは非推奨になりました。8月10日付ではBigQuery AI functionsが gemini-3.1-flash-lite と gemini-3.5-flash のGAモデルをサポートしました。対象エンドポイントは us、eu、global です。

CX Agent Studio / Google Cloud CCaaS

Announcement最終: 8/10公式ソース

Google Cloud CCaaS 6.0が公開されました。内容は内部インフラ更新で、5.2からの顧客向け変更はありません。反映タイミングは選択しているdeployment scheduleに依存するため、更新ウィンドウや監視対象を管理している場合にだけ確認します。

Cloud SDK / gcloud CLI

Breaking / CLI最終: 8/11公式ソース

Cloud SDK 580.0.0で、Snap版 google-cloud-sdk パッケージが2026年9月29日に廃止・削除される予定であることを確認しました。Linux SnapでCLIを導入している環境は google-cloud-cli パッケージへの移行が必要です。Windows運用や通常インストーラ利用には直接影響しません。

Cloud Run

Feature / GPU最終: 8/11公式ソース

Cloud RunでNVIDIA L4 GPU driver 580.x.xがservices、jobs、worker poolsで利用可能になりました。GPUを使う推論・バッチ処理向けの基盤更新で、通常のWebhook、API、チャットボット連携サービスには直接影響しないため、ホット対象にはしていません。

ChatPlus

Service / AI Agent最終: 8/10公式ソース

8月10日に、AIエージェント導入から運用定着までを支援する「AXソリューション」が公開されました。AXコンサルティング、ChatPlus / AI AgentPlusを基盤とした構築支援、個別要件に応じたカスタム開発を含む伴走型サービスです。FAQトップは今回も取得できませんでした。
