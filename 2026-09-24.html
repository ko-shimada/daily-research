詳細

CX Agent Studio

🔥 voicebot最終: 9/21公式ソース

Google Cloud CCaaS 6.15の事前リリース情報で、仮想エージェントから有人キューへ転送できない問題、仮想エージェントでデフレクトした通話の録音欠落・誤紐付け、IVR通話のcustom wrap-up eventがDialogflow CXへ送信されない問題などの修正が予告されました。日本語ボイスボットの通話転送、録音、Dialogflow CX連携に直接関係するため、hotProjectsはvoicebotに設定しています。

9月18日にはGoogle Cloud CCaaS 6.13が正式リリースされ、モバイル着信のエンドユーザー側通話失敗、agent desktopの通話・チャットデータ消失、転送先エージェントの通話中状態残留、チャット終了イベント重複などが修正されました。前回レポートでは事前リリース情報までの掲載だったため、本レポートで正式リリースを補完しました。

BigQuery

Preview / GA最終: 9/22公式ソース

9月22日、BigQuery data agentをAgent Registryへ登録し、Google管理認証情報でGemini Enterpriseへ取り込める機能がPreviewになりました。同一Google Cloud projectかつAgent Gateway regionが一致する場合、A2A JSON cardやOAuth client credentialsの手動設定が不要になります。

9月21日には、BigQuery StudioのQuery results paneで直近のクエリ実行履歴を確認する機能がGAになり、BigQuery generative AI functionsがgemini-3.8-flashに対応しました。いずれも現行利用を確認できないため、hotProjectsは設定していません。

Vertex AI / GenAI / Agent Platform

Breaking / SDK最終: 9/22公式ソース

9月22日、Gemini Enterprise Agent PlatformのModel GardenでAnthropic Claude Opus 5.5が利用可能になりました。9月21日にはAgent Platform WorkbenchのJupyterLabで、console errorや未処理例外、network request failureなどのclient-side logをinstance backendへ転送し、Cloud Loggingで確認できるようになりました。

9月18日にはAgent Platform SDK for Python google-cloud-agentplatform 2.0.1が公開されました。生成AIモジュールのGoogle Gen AI SDK移行、agent surfaceのgoogle-cloud-aiplatformから専用packageへの分離、namespace再編を含むBreaking changeです。現行コードでのSDK利用は確認できないため、hotProjectsは設定していません。

Cloud SDK / gcloud CLI

Breaking / Deprecation最終: 9/22公式ソース

Cloud SDK 586.0.0では、同梱KustomizeとKptが削除されました。google-cloud-sdk Snap packageは9月29日、gcloud-man-pagesは590.0.0で削除予定です。Cloud Servicesのgcloud services api-keys createとupdateでは--api-target制限が必須になり、--clear-restrictionsが削除されました。該当する配布方式やscriptがある場合は移行確認が必要です。

Genesys Cloud

直接影響なし最終: 9/21公式ソース

9月21日リリースにはLAM-powered virtual agents、Mobile Messengerのuser tracking、Apple Messages for Business、performance view改善などが含まれます。現行の日本語ボイスボットでの利用を確認できず、Dialogflow CX integration、Architect inbound flow、STT/TTSへの直接変更ではないため、🔥対象にはしていません。
