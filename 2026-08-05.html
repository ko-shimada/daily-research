Vertex AI / GenAI / Agent Platform

Feature / Security最終: 8/4公式ソース

Gemini Enterprise の data connector workflow で end-to-end tracing が拡張され、`execute_tool` と `invoke_connector` をTrace Explorerで追跡できるようになりました。あわせてSecurity Command Centerで、Cloud Run / Agent Platform向けのMalicious Skill runtime threat detectorsが追加されました。会話エージェントの外部データ連携やWebhook実行環境では、障害解析、監査、検出通知の確認対象です。

BigQuery

Restored / GA最終: 8/3公式ソース

`VECTOR_SEARCH`と`AI.SEARCH`のHYBRID modeによるハイブリッド検索が復旧しました。FAQ検索、RAG、会話ログ分析で該当クエリを使う場合は、検索品質とレスポンスの復旧確認が必要です。BigQuery JDBC driver の OpenTelemetry tracing / logging 対応GAと、cross-cloud connections全リージョンPreviewも確認しました。

Cloud SDK / gcloud CLI

Breaking / CLI最終: 8/4公式ソース

Google Cloud CLI 579.0.0で`gcloud api-registry mcp enable`と`gcloud api-registry mcp disable`が削除されました。MCP server有効化は不要になり、基盤サービスの有効化で足りる扱いです。`gcloud ai`の`us`マルチリージョン要求はVertex AI multi-regional endpointへルーティングされます。

CX Agent Studio / Google Cloud CCaaS

Prerelease / Analytics最終: 8/3公式ソース

Google Cloud CCaaS Advanced Reporting dashboardの修正予告を確認しました。仮想エージェントの通話数、平均待ち時間、エージェント別チャット数、平均処理時間、チャネルグループ表示など、dashboard集計に関わる修正が含まれます。会話分析dashboardを使っている場合は、反映後のKPI差分を確認対象にします。

VPC Service Controls

Google Antigravity in Gemini Enterprise連携がPreviewとして追加されました。現行のDialogflow CX、CX Agent Studio、Storage、BigQuery連携への直接影響は確認していません。
