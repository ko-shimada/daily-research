概況

BigQueryでは、リージョン間テーブルコピーと会話型分析エージェントの回答をPDF・CSVへ出力する機能がGAになりました。Cloud Storageでは画像・PDFの解析情報をオブジェクトに付与する機能などがPreviewです。VPC Service ControlsではGKE Workload Identity Federationを境界ルールに使う機能がPreview、Cloud Runでは予算上限によるワークロード停止がGAになりました。

ChatPlus公式ニュースには10月15日付の受賞発表が掲載されていますが、サービス機能変更ではありません。FAQ・お知らせは取得できませんでした。Genesys Cloudの10月12日更新はAgentic Virtual AgentsやAI Studio向けで、日本語ボイスボットへの直接影響は確認できていません。東京・大阪は正常、UAEでは重大障害が継続しています。Google Cloud Service Healthに広域障害表示はありません。

詳細

BigQuery

10月15日、リージョン間テーブルコピーがGAになりました。また、会話型分析エージェントの回答（文章、図表、表、引用）をPDFまたはCSVで出力できる機能がGAです。GoogleSQLではSELECT句に付けた別名を同じSELECTリスト内や同じクエリブロックのWHERE句で参照できるようになりました。この機能はオプトインで、事前の有効化が必要です。利用状況は未確認です。

Cloud Storage・VPC Service Controls・Cloud Run

Cloud Storageでは、対象の画像・PDFに機械学習モデルで解析したメタデータを付与するObject enrichmentsと、Object contextsの拡張データ取得が10月13日にPreviewとなりました。VPC Service Controlsでは10月14日、GKEのWorkload Identity Federation主体をサービス境界のIngress・Egressルールで指定できる機能がPreviewになりました。いずれも実環境での利用状況は未確認です。

Cloud Runでは10月12日、予算消費上限に応じてワークロードを停止するBudget spend capsがGAになりました。対象プロジェクトでの設定有無は未確認です。

Genesys Cloud・ChatPlus・サービス状態

Genesys Cloudの10月12日更新には、Agentic Virtual Agentsの会話フックや知識ツール設定、AI Studioのツール入力事前条件が含まれます。対象はAgentic Virtual Agents等であり、利用実態も確認できないため、日本語ボイスボットへの直接影響は未判定です。ステータスでは東京・大阪がOperational、UAEはMajor Outageと表示されています。10月15日の新規インシデントはありません。

ChatPlus公式ニュースの10月15日掲載はITreviewの受賞発表で、サービス機能の変更ではありません。FAQ・お知らせページは取得できず、メンテナンス告知の有無は確認できませんでした。
