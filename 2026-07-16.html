BigQuery

Preview / Security最終: 7/15公式ソース

データガバナンスタグがPreviewになりました。機密列にResource Managerタグを付与し、BigQueryデータポリシーで条件付きアクセス、列レベルセキュリティ、データマスキングを制御できます。会話ログ、ユーザー属性、問い合わせ履歴などをBigQueryに集約している場合、タグ設計と既存ポリシーの整理候補です。

Vertex AI / GenAI / Agent Platform

GA最終: 7/15公式ソース

Gemini Enterprise Agent PlatformのMemory Bank memory profilesがGAになりました。固定スキーマで構造化プロフィールを作成し、LLMにより情報を更新する仕組みです。セッション中の検索コストを下げつつ、利用者属性や会話上の継続情報を参照する設計に関係します。

CX Agent Studio / Google Cloud CCaaS

Prerelease / Chat最終: 7/15公式ソース

Google Cloud CCaaS prereleaseで、Agent Assist hub、手動wrap-up、チャットのAPI direct access point(DAP)が予告されました。DAPは外部APIエンドポイントの応答に基づき、エンドユーザーにキュー選択をさせずにチャットセッションを自動ルーティングする機能です。あわせて、Webチャットでエンドユーザーにメッセージが届かない問題、キューに残って割り当てられない問題、仮想エージェント転送後の扱いなど、チャット/仮想エージェント運用に関係する修正も掲載されています。
