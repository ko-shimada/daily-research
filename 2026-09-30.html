詳細

BigQuery

GA / Preview / MCP掲載: 9/29公式ソース

AI.KEY_DRIVERS関数がGAになり、合計可能な指標に統計的に有意な変化を与えるデータ区分を特定できます。managed disaster recoveryを使う予約では、INFORMATION_SCHEMA.FAILOVER_HISTORYからフェイルオーバー履歴をほぼリアルタイムに取得する機能がPreviewになりました。

9月28日付でBigQuery Data Transfer Service MCP serverのGAも追加確認しました。いずれも現行分析基盤への直接影響を確認できないためhotProjectsは設定していません。

Cloud Run

GA掲載: 9/29公式ソース

CPU使用率または同時実行数のカスタム目標値を指定するスケーリング制御がGAになりました。既定値を変更しているサービスではスケール判断に関係しますが、現行Webhook構成への直接影響を確認できないためhotProjectsは設定していません。

Cloud SDK / gcloud CLI

Breaking掲載: 9/29公式ソース

Cloud SDK 587.0.0でgcloud storage buckets anywhere-caches pauseと、非推奨だったDistributed Cloud EdgeのVPN接続コマンド群が削除されました。Python 3.15対応、semantic governance policyの拒否時メッセージ指定、Agent Registry binding作成時の--source-identifier省略対応も追加されました。削除対象コマンドの現行利用を確認できないためhotProjectsは設定していません。
