VPC Service Controls

GA / Security最終: 8/6公式ソース

VPC Service Controlsのservice patternsがGAになりました。private.googleapis.comまたはPrivate Service Connect endpointのall-apis bundleを使う場合に、サービス境界内のVPCからアクセスできるGoogle APIを明示的に構成できます。Dialogflow CX、CX Agent Studio、Cloud Storage、BigQueryなどを境界内で連携させる構成では確認対象です。

CX Agent Studio / Google Cloud CCaaS

Fixed / Analytics / CCaaS最終: 8/6公式ソース

Google Cloud CCaaS Advanced reporting dashboards 5.1が公開されました。仮想エージェント通話メトリクス、チャットのQueue Abandons / Abandon %、Queue Time filter、Available Agents、転送済み通話がQueuedに見える問題、7日を超えるdate rangeのエクスポート失敗などが修正されています。会話運用レポートでCCaaS dashboardを参照している場合、リリース反映後に前後比較を確認します。

ChatPlus

Feature / AI AgentPlus最終: 8/4公式ソース

8月4日付の7月アップデートまとめで、AI AgentPlusの役割プロンプト最適化、学習対象URL／学習対象外URL、訪問ページURLや訪問者属性によるAIエージェント割り当て条件が追加されました。ツリーエディタでは初回メッセージへの遷移アクション、レポートではURL別チャット数も追加されています。FAQトップは本文取得に失敗しました。
