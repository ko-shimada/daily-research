詳細

Genesys Cloud

音声運用掲載: 9/28公式ソース

クラウドメディアの同時通話セッション使用数と設定済み容量を、管理者が組織単位でリアルタイム確認できるようになりました。繁忙時の負荷監視、容量計画、障害切り分けを支援する運用機能です。通話処理仕様の変更ではないためhotProjectsは設定していません。

同日リリースのArchitect Bot Flow更新と、利用を確認できないagentic virtual agentsモデルの非推奨化は、Genesysの選定基準に従い🔥対象外です。

Cloud Run

Preview掲載: 9/28公式ソース

Cloud Runサービスにexample.cloud.runのようなグローバルなカスタムURLを設定する機能がPreviewになりました。公式説明ではDNS設定、ロードバランサー、追加費用は不要です。現行Webhook構成への直接影響を確認できないためhotProjectsは設定していません。

Vertex AI / GenAI / Agent Platform

API / IAM / Model掲載: 9/28公式ソース

Gemini Enterprise Agent PlatformのInteractions APIがGemini 3モデルにPreview対応しました。Gemini Enterpriseでは、アプリとデータストアごとにAdmin、Viewer、User権限を割り当てるリソース単位IAMも追加され、Google Cloudコンソール、CLI、REST APIから管理できます。

Model GardenではAnthropic Claude Sonnet 5.5が利用可能になりました。いずれも現行エージェントへの直接影響を確認できないためhotProjectsは設定していません。

BigQuery

Streaming掲載: 9/28公式ソース

BigQuery continuous queriesが生成した行を、INSERT DMLでApache Iceberg managed tablesへ直接書き込めるようになりました。現行分析基盤への直接影響を確認できないためhotProjectsは設定していません。

Cloud SDK / gcloud CLI

移行期限確認: 9/29 JST公式ソース

Cloud SDK 586.0.0で告知されたgoogle-cloud-sdk Snap packageの削除予定日は本日9月29日です。利用している場合はgoogle-cloud-cli packageへの移行が必要です。最新版は586.0.0のままで、削除実施を示す新しいリリース掲載はありません。
