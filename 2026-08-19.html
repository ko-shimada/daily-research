Cloud SDK / gcloud CLI

Breaking / CLI最終: 8/18公式ソース

Google Cloud公式リリースノートで、Cloud SDK 581.0.0（8月18日付）の破壊的変更を確認しました。MCP有効化が不要になったことに伴い、gcloud beta services mcp enable、gcloud beta services mcp disable、gcloud beta services mcp listが削除されました。これらを自動化スクリプトに含めている場合は削除してください。ボイスボット／チャットボットの本番機能に直接影響するサービス変更は確認していません。
