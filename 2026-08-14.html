詳細

Vertex AI / GenAI / Agent Platform

GA最終: 8/13公式ソース

Gemini EnterpriseでGemini 3.7 Flashモデルがglobal、us、euリージョンでGAになりました。管理者がGemini Enterpriseアプリで有効化できます。Google Cloudリージョン基準のus/globalに該当するため、Agent Platform上でGemini系モデルを指定している場合はモデル切り替えの確認対象です。あわせて、再利用可能なカスタム指示を作成・アップロード・共有できるCustom SkillsもGAになりました。Vertex AI個別release notesの最新は8月9日のAgent Platform Workbench更新のままです。

VPC Service Controls

Preview / Feature最終: 8/13公式ソース

サービス境界の最適化を支援するVPC Service Controls recommenderがPreviewで追加されました。境界外で稼働する機密リソース(BigQuery、Cloud Storage等)の情報持ち出しリスク、境界内で未設定のアクセス可能API、許可APIと実際のアクセス範囲が食い違う誤設定を検出します。Dialogflow CX、CX Agent Studio、Storage、BigQueryを境界内で連携させている場合、既存の境界設計レビューへの活用候補です。

CX Agent Studio / Google Cloud CCaaS

Prerelease / Fixed最終: 8/12公式ソース

Google Cloud CCaaS prerelease notesで、次期バージョンのagent desktopカスタムパネルURLへのパラメータ渡し対応、callback offerの制限設定に加え、チャット／コール処理に関する50件超の不具合修正が予告されました。音声・チャット双方の会話エージェント運用に関わるため、次期リリース反映時の動作確認対象です。

ChatPlus

予告 / 仕様変更最終: 8/14公式ソース

ChatPlus FAQで、AI AgentPlus(AIチャットボットプラン)学習機能の仕様変更案内を確認しました。手動実行していた「高速化」処理を自動実行に標準化し、パーツ名称も「生成AIドキュメント連携(高速化)」→「学習データから回答」等に変更されます。2026年9月3日実施予定で、初回実行中は学習データの追加・更新ができません。News最新は8月10日の「AXソリューション」公開のままです。

Genesys Cloud

Incident / Status確認: 8/14 JST公式ソース

Release notes最新は8月10日のままで、8月13日以降の新規更新は確認していません。StatusではAsia Pacific (Tokyo) と Asia Pacific (Osaka) はOperational、EMEA (UAE) PlatformはMajor Outageとして監視継続中です。日本語ボイスボット対象リージョンへの直接影響は確認していません。
