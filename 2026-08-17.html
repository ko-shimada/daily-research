Vertex AI / GenAI / Agent Platform

Preview / Feature最終: 8/15公式ソース

Google Cloud release notesで8月15日付を確認しました。Gemini Enterprise Agent Platformで、semantic governance policy(セマンティックガバナンスポリシー)の実行状況をCloud Monitoringで追跡できる監視メトリクスがPreviewで追加されました。リクエストのスループット、評価件数、レイテンシ、判定結果の分布、LLMトークン消費量をMetrics Explorer、Cloud Monitoring API、PromQL、アラートポリシーから参照できます。Agent Platformでガバナンスポリシーを運用している場合、ポリシー適用状況の監視・アラート設計の確認対象です。あわせて8月14日付で、Gemini EnterpriseモバイルアプリでもGemini 3.7 Flashを選択できるようになりました(管理者による機能有効化が必要)。8月13日にGAとなったglobal/us/euリージョンでの提供を補完するもので、Agent Platform APIの仕様変更ではありません。同日、Agent Identityリソース(AuthProvider等)の特定フィールドに対する組織ポリシーのカスタム制約設定もGAになりました。Agent Identity機能を利用している場合の権限設計強化の選択肢です。Vertex AI個別release notesの最新は8月9日のAgent Platform Workbench更新のままです。
